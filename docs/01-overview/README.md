# 01. 프로젝트 개요

> 설계 문서. 이 저장소에는 현재 애플리케이션 코드가 없으며 아래 기능은 구현 예정입니다.

## 소개와 배경

알고리즘 13반 기말발표 주제 **B04 복면산(Cryptarithm)**의 교육용 웹 시뮬레이터다. 터미널의 정답 출력만으로는 숫자 배정, 자리올림, 가지치기와 복귀 과정을 청중이 따라가기 어렵다. 사용자가 직접 입력한 복면산을 Python 알고리즘으로 풀고 실제 탐색 기록을 브라우저에서 단계별로 보여 주어 백트래킹의 동작을 설명한다.

## 목적과 사용자

- 발표 청중과 학습자가 후보 선택, 제약 검사, 자리별 계산, 자리올림, 가지치기, 백트래킹 및 정답 검증을 이해한다.
- 발표자와 학습자가 예제 또는 직접 입력한 문제를 실행하고 완전탐색과 백트래킹의 결과 및 비용을 비교한다.
- 정확성과 설명력을 우선하고 발표에 적합한 시각적 완성도를 갖춘다.

## 범위와 기술

초기 범위는 영문 문자로 구성된 두 피연산자의 덧셈 복면산이다. 직접 입력, 예제 채우기, 문제 풀이, 실행 기록 재생, 결과 및 성능 비교를 계획한다. Windows 로컬 환경에서 Python/Flask 서버와 HTML, CSS, JavaScript 브라우저 화면을 사용한다. 외부 API와 데이터베이스는 사용하지 않는다.

회원가입, 인증, 세션, 사용자 데이터 영구 저장, 클라우드 배포, 뺄셈·곱셈·나눗셈·음수 및 세 개 이상의 피연산자는 범위에서 제외한다. 기록과 계산 제한에 따른 부분 결과는 전체 결과와 구분한다.

## 담당과 기대 효과

| 담당 | 역할 |
|---|---|
| 구윤찬 | 개발 |
| 송준영 | 발표자료 및 약 5분 발표 영상 제작 |

실행 결과를 시각적으로 추적하고 완전탐색과 가지치기의 차이를 관찰함으로써 알고리즘의 원리를 설명하는 것이 기대 효과다.
