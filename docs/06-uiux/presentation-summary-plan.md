# 발표용 장면 요약 구현 계획

목적: 실행 기록 수를 줄이는 요약에서, 청중에게 알고리즘을 설명하는 장면 요약으로 전환한다. 기존 숫자 배정의 인과관계와 예제 전환 시 재생기 정리 규칙을 유지한다.

기본 보기에는 문제 이해, 숫자 배정, 실제 실패, 복귀·재시도, 자리 계산·올림, 정답·종료의 핵심 장면을 배치한다. 실제 실행 순서를 따르며 없는 실패나 정답을 만들지 않는다. 구현 후 기본 예제의 장면 수는 4~10개로 확인했다. 각 장면은 실제 이벤트 스냅샷 하나, 제목, 계산식, 짧은 설명과 현재 계산·알고리즘 구조에 대한 설명으로 이루어진다. 장면 사이에는 의도적인 구분을 둔다.

발표자는 이전/다음 장면과 장면 목차를 직접 누른다. 자동 재생은 선택 기능으로 제공하고 장면당 충분한 시간을 둔다. 기본 발표용 요약, 기존 단계별 요약, 전체 기록을 구분한다. 발표 화면에서는 세부 기록·큰 원본 이벤트 수를 접고 설명과 계산에 집중한다.

검증: 장면 앵커가 실제 요약 이벤트와 일치하는지, 덧셈·올림 설명이 스냅샷과 맞는지, 해 없음·제한 중단을 정확히 말하는지, 예제를 전환해도 수식이 섞이지 않는지 검사한다. 기본 예제와 SEND 비교를 실제 1280×720에서 확인한다. PPT·영상 제작이나 이미 검증한 전체 기록 API 변경은 범위에 넣지 않는다. 구현 후 확인 결과는 [최종 종합 QA](../07-todo-list/final-qa-2026-11-14.md)를 참고한다.
