# 발표 시연 순서

목표 약 5분. 다음은 촬영용 순서이며 실측 리허설과 최종 PPT·영상은 아직 완료하지 않았다.

1. 0:00~0:40: 같은 문자/다른 문자/선행 0 규칙을 설명한다.
2. 0:40~1:20: I + BB = ILL을 비교로 실행하고 발표 화면으로 전환한다. 발표용 요약의 두 패널에서 다음 장면과 번호 목차를 조작한다. 필요하면 방향키로 넘긴다.
3. 1:20~2:30: 백트래킹의 오른쪽 자리 계산과 올림을 멈춰 설명한다. 결과 숫자 충돌에서 더 높은 자리 후보를 제외하고 이전 배정으로 복귀하는 것을 보여 준다.
4. 2:30~3:20: 실제 최종 답 1 + 99 = 100과 통계를 보여 준다. 완성 배정 검사는 완전탐색 576회, 백트래킹 1회다. 가지치기 수 자체가 더 적어야 빠른 것은 아님을 설명한다.
5. 3:20~4:10: 일반 화면으로 돌아가 SEND + MORE = MONEY를 실행한다. 요약에서 실제 정답과 종료를 확인한다. 전체 기록은 페이지로 실제 마지막 단계까지 조회할 수 있지만 발표에서는 장면 요약을 사용한다. 발표에서 전체 기록 자동 재생을 끝까지 기다리지 않는다.
6. 4:10~4:40: A + B = C의 여러 해 또는 A + B = AA의 해 없음을 보여 준다.
7. 4:40~5:00: 자리별 제약 검사로 후보를 일찍 제외하는 이유를 정리한다.

각 패널의 재풀이 버튼은 해당 알고리즘만 재계산한다. 최초 비교 실행은 두 알고리즘을 순차 계산한다. 실행 시간에는 기록 생성 비용이 포함되므로 순수 알고리즘 벤치마크라고 설명하지 않는다. 실제 발표 PC가 느리면 시간 제한에 걸릴 수 있으므로 사전 실행이 필요하다. 측정 근거는 [수정 후 검증](remediation-verification-2026-11-14.md)을 참고한다.
