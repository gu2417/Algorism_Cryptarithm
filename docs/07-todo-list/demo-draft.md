# 발표 시연 준비안

> 초안. 실제 브라우저 시연과 시간 측정 후 확정한다.

1. 복면산에서 같은 문자는 같은 숫자, 서로 다른 문자는 다른 숫자이며 여러 자리 수의 첫 숫자는 0이 될 수 없음을 설명한다.
2. `I + BB = ILL` 예제를 선택하고 백트래킹을 실행한다. 후보 선택과 문자 배정, 일의 자리 계산 및 자리올림을 다음 단계로 넘기며 보여 준다.
3. 충돌이 발견되면 가지치기 이유와 배정 해제를 확인해 이전 상태로 돌아가는 과정을 설명한다. 자동 재생과 일시정지도 시연한다.
4. 결과의 정답, 숫자 배정과 탐색 통계를 확인한다. 문제를 직접 입력해 풀이가 실제 실행된다는 점을 보여 준다.
5. `SEND + MORE = MONEY`를 실행해 확장 예제를 보여 준다. 이 예제는 측정 시 기록 상한에 도달했으므로 탐색 기록은 앞부분만 보여 주고 최종 해는 결과 영역에서 확인한다.
6. 두 알고리즘 비교 시 실행 제한과 기록 생성 비용이 결과에 영향을 줄 수 있음을 설명한다.

발표 시간은 약 5분을 목표로 한다. 실제 재생 속도, 화면 가독성, 전환 순서 및 총 소요 시간은 브라우저 리허설에서 확인해야 한다. 측정 근거와 검증 한계는 [통합 검증 보고서](integration-verification.md)를 참고한다.
