숫자 배정 범위, 선행 0 제외, 모든 완성 배정 검사라는 완전탐색의 의미를 유지한다. 정답 하드코딩, 자리 계산을 이용한 중간 가지치기, 완료 상태 위조는 사용하지 않았다. 최적화 경로와 상세 기록 경로의 해·통계·이벤트 순서가 같은지를 회귀 테스트로 검증한다.

## 실제 서버 측정

브라우저에서 사용하는 `trace_view: "summary"` 요청을 로컬 HTTP로 실행한 결과다. JSON 크기는 응답 본문, HTTP 시간은 요청 시작부터 응답 읽기 완료까지이며 브라우저 렌더링은 제외한다. 컴퓨터 부하에 따라 값은 달라진다. [원자료](verification-assets/fixed-audit-data.json).

| I + BB = ILL | 백트래킹 | 완료 | 1 | 3.86 | 36.93 | 10,994 |
| I + BB = ILL | 완전탐색 | 완료 | 1 | 16.09 | 107.73 | 8,719 |

| A + A = A | 완전탐색 | 완료 | 1 | 0.29 | 8.58 | 3,129 |

아래 항목은 실제 Chromium에서 서버와 연결해 확인한 내용이다.

- SEND 비교에서 양쪽 모두 탐색 완료. 완전탐색의 완성 배정 검사 1,451,520회, 배정 시도 2,103,931회, 선행 0 제외 15,121회.
- 실제 브라우저 비교 실행의 완전탐색은 약 3.7초, 한쪽 재계산은 약 4.2초로 완료했다. 환경이 느리거나 부하가 높으면 5초 제한은 여전히 적용된다.
- 백트래킹 요약 56단계, 완전탐색 요약 48단계 끝에서 정답과 탐색 종료 표시. 마지막 후보 대신 실제 발견한 정답을 계산판에 표시.
- 한쪽만 재계산했을 때 상대 재생 위치 보존. 전체 보기 선택 시 실제 80,000개 저장 버퍼 조회 성공.
- 1280×720 발표 모드에서 양쪽 패널 하단 y≈667px, 페이지 가로 너비 1280px. [발표 화면](verification-assets/fixed-presentation-1280.png).
- 375×812에서는 세로 비교 배치, 페이지 가로 너비 375px. [모바일 화면](verification-assets/fixed-mobile.png).
- 확인 중 브라우저 콘솔 오류 없음. Playwright MCP는 사용하지 않음.

## API와 데이터 보관

기존 `POST /api/solve` 호출은 호환된다. `trace_view`를 생략하거나 `full`로 요청하면 기존처럼 저장된 전체 기록을 즉시 반환한다. 웹 UI는 `summary`로 요청해 `trace: []`, `trace_total`, `trace_token`, `summary_trace`, `events_seen`을 받는다. 전체 보기에서 `GET /api/traces/<token>`을 요청한다.

전체 기록은 서버 프로세스별 최근 4개 실행, 실행별 10분 동안만 조회 가능하다. 만료되거나 최근 실행에 밀리면 404와 재풀이 안내를 반환하고 UI는 사용 가능한 요약으로 돌아간다. 데이터베이스·쿠키·영구 실행 이력은 추가하지 않았다.

## 남은 한계와 제출 판단

**로컬 기능 시연의 주요 결함은 수정하고 재검증했다.** 현재 버전으로 발표 화면을 준비할 수 있다. 다만 다음 사항까지 완료됐다고 주장하지 않는다.

1. 전체 보기는 실제 전체 탐색의 모든 이벤트가 아니라 저장 상한 80,000개까지의 앞부분이다. SEND 완전탐색은 약 774만 이벤트가 발생하며, 실제 정답·종료는 별도 요약으로 제공한다. 전체 기록을 선택하면 큰 버퍼의 전송 비용이 발생한다.
2. 기본 비교의 풀이 시작은 두 알고리즘을 순차 계산한다. 계산 이후 각 패널의 재풀이 요청과 재생은 독립적이다. 두 계산의 동시 스트리밍 실행 기능은 아니다.
3. 실행 시간은 기록 생성 비용을 포함한다. 컴퓨터 부하가 크면 시간 제한에 걸릴 수 있고, 강제 실시간 보장은 아니다.
4. PPT·영상 결과물 작성과 실제 5분 리허설, 발표장 프로젝터 가독성 확인은 남아 있다. Todo의 T25는 진행 중, T26은 미착수로 유지했다.
5. 깨끗한 PC 설치, 여러 브라우저·스크린리더, 장시간 메모리·동시 부하 검증은 이번 범위에 포함하지 않았다.
6. 변경 사항은 로컬 미커밋 상태다. PR 생성·병합은 아직 수행하지 않았다.
