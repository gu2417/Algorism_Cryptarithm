## 실제 브라우저 검증 추가

로컬 Flask 서버와 Chromium에서 직접 확인했다. `I + BB = ILL`은 `1 + 99 = 100`, `SEND + MORE = MONEY`는 `9567 + 1085 = 10652`를 표시했다. 후자는 기록 10,000개 제한 안내를 표시했다. 잘못된 연산자 안내, 이전·다음·재시작, 실제 시간의 자동 재생과 일시정지, 5배속 선택, 비교 모드, 여러 해 목록, 해 없음과 콘솔 오류 없음을 확인했다. 데스크톱 1280×720 및 모바일 375×812 화면을 확인했다.

모바일에서 50자 단어가 포함된 유효 수식을 실행하면 페이지 너비가 1,907px까지 증가했다. 계산 격자의 최소 너비와 스크롤 범위를 조정한 후 같은 375px 화면에서 페이지 너비가 375px임을 확인했다. 긴 식은 계산 영역 내부에서 가로 스크롤한다. 여러 기기, 스크린리더 및 장시간 부하 검증은 수행하지 않았다.
