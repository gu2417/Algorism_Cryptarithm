## 발견하고 수정한 문제

### 모바일 비교 패널 헤더의 과도한 줄바꿈

- 재현: 375×812, I + BB = ILL, 두 알고리즘 비교, 일반 화면.
- 원인: 제목·상태·재풀이 버튼을 `flex-wrap: nowrap`인 한 행에 배치했다. 가용 너비가 부족해 버튼이 약 59px 너비·111px 높이로 줄어들고 제목도 두 줄로 나뉘었다.
- 수정: 패널 헤더가 가용 너비에 맞춰 다음 행으로 넘어가게 하고 제목·재풀이 버튼의 과도한 글자 줄바꿈·축소를 막았다. 480px 이하에서는 세로로 배치하며 넓은 발표 화면의 배치는 유지한다.
- 확인: 320·375·481·901·1280px 너비에서 양쪽 버튼이 약 157px 너비·35px 높이의 한 줄로 표시되고 제목은 한 줄로 표시됐다. 페이지 가로 넘침은 없었으며 실제 재풀이와 보기 전환도 동작했다.
- 근거: [수정 전 긴 수식 비교 화면](verification-assets/main-release-mobile.png), [수정 후 기본 예제 비교 화면](verification-assets/main-release-mobile-after.png). 전후 이미지는 서로 다른 예제이며, 위 치수 비교는 같은 I + BB = ILL에서 별도로 측정했다.

문서에서는 안정 버전 설치 안내를 main 체크아웃으로 맞추고, 이번 검증 보고서와 개발 브랜치의 구분을 추가했다. CHANGELOG는 main에 처음 들어가는 Core·API·UI와 모바일 수정까지 포함하도록 정리했다.

현재 저장소에는 GitHub Actions 검사·배포 워크플로가 없다. 본 보고서의 테스트 통과는 로컬 실행 결과이며 CI 통과로 표현하지 않는다. 비밀키·환경 파일·검증용 가상환경·임시 브라우저 실행 파일은 PR 산출물에 포함하지 않는다.
