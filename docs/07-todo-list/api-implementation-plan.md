# 풀이 API 구현 계획

**목표:** 문서의 풀이 API와 독립적인 시간·해·기록 제한을 구현한다.

**기준:** [아키텍처](../03-architecture/README.md). Core에 협조적 중단 지점을 추가하고 Feature가 실행별 상태와 제한을 관리하며 Module이 HTTP 입력과 출력을 처리한다.

1. API 테스트에서 정상·잘못된 입력과 각 제한의 동작을 정의하고 실패를 확인한다.
2. 두 알고리즘에 후보·재귀 검사 및 통계 수집을 추가하고 제한 시 부분 해를 보존한다.
3. 기록 상한은 탐색을 멈추지 않게 처리하고 Flask에서 검증된 응답을 반환한다.
4. 전체 단위·API 테스트로 해 없음, 부분 결과, 비교, 기록 절단 및 Core 회귀를 검증한다.
